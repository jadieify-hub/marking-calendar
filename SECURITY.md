# Безопасность

## Поддерживаемые версии

Исправления безопасности выпускаются для последней доступной версии приложения. Пользователям предыдущих версий рекомендуется обновиться перед отправкой отчёта.

## Как сообщить об уязвимости

Пока репозиторий закрыт для внутреннего использования, сообщайте об уязвимостях разработчику по принятому в вашей организации приватному каналу. Не создавайте Issue с описанием ещё не исправленной уязвимости.

Перед открытой публикацией для репозитория будет включён GitHub Private vulnerability reporting. После этого приватный отчёт можно будет отправить через `Security` → `Report a vulnerability`.

Укажите версию приложения, версию Windows, последовательность воспроизведения и ожидаемое поведение. Прикладывайте только минимально необходимый фрагмент журнала. Перед отправкой удалите имена пользователей Windows, полные локальные пути, имена компьютеров и иные персональные сведения.

Отчёт будет проверен разработчиком, после чего через приватное обсуждение будет сообщено, подтверждена ли проблема и требуется ли дополнительная информация.

## Локальные данные

Приложение не отправляет телеметрию и журналы автоматически. Диагностический журнал может содержать сообщения исключений и локальные пути, поэтому его нельзя публиковать без предварительной проверки.

Официальными считаются только сборки из [GitHub Releases](https://github.com/jadieify-hub/marking-calendar/releases). Их контрольные суммы публикуются в `SHA256SUMS.txt` соответствующего релиза.
