# Оформление CloudTips

Фон платежной формы: `calendar-cloudtips-480x220.png` (480×220 px, PNG).

Страница приложения: `https://pay.cloudtips.ru/p/53698013`.

## Текст

- Текст на странице оплаты: `Поддержать «Календарь маркировки»`
- Текст благодарности: `Спасибо! Ваша поддержка помогает развивать приложение.`
- Сумма: произвольная, в рублях.
- Поле «Комментарий»: включено, необязательное.
- Имя, обязательное поле и обратная связь: выключены.

## Исходник изображения

`calendar-cloudtips-source.png` — полноразмерный исходник для будущих вариантов.

Изображение создано встроенным генератором изображений по промпту: темный профессиональный баннер Windows-приложения «Календарь маркировки» с календарной сеткой, сине-фиолетовым акцентом и цветными маркерами категорий; без логотипа «Честного знака», QR-кода, платежных символов и постороннего текста.
