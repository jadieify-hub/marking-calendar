# Календарь маркировки 0.1.23

Теперь календарь по товарным группам и категориям клиента можно распечатать или сохранить в PDF. Под фильтрами добавлены две отдельные кнопки: **Печать** открывает предпросмотр и выбор принтера, **Сохранить PDF** — выбор папки и имени файла.

- В документ входят все события по текущим фильтрам, включая ещё не раскрытые кнопкой «Показать ещё».
- Таблица содержит сроки, товарные группы, типы и полные описания событий, дату данных и выбранные категории.
- Формат PDF — A4, альбомная ориентация, белый фон независимо от темы приложения. Заголовки таблицы повторяются на каждой странице.
- Ctrl+P формирует таблицу с актуальными фильтрами. Печать и экспорт не изменяют сохранённый профиль.

Проверены фильтрация, команды интерфейса и многостраничный PDF через WebView2: все 80 событий и их описания сохранены полностью.

## Обновление

Установленная версия загрузит обновление автоматически. Для ручного обновления запустите `MarkingCalendar-Setup.exe` поверх текущей версии. Для Portable замените файлы программы новым архивом. Профиль и настройки сохраняются.

## Файлы

- `MarkingCalendar-Setup.exe` — установщик Windows x64.
- `MarkingCalendar-Portable.zip` — архив без автообновления.
- `SHA256SUMS.txt` — контрольные суммы.
- `releases.win.json` и `MarkingCalendar-0.1.23-full.nupkg` — файлы автообновления.
