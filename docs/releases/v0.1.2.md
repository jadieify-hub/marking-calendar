# Календарь маркировки 0.1.2

Первый подготовленный выпуск локального календаря этапов обязательной маркировки для Windows.

## Что входит

- единая календарная лента с группировкой событий по дате и товарной группе;
- блок ближайших событий, поиск и фильтры по товарным группам и категориям;
- персональный набор групп и первоначальная настройка профиля;
- краткий обзор интерфейса при первом запуске с повторным открытием из справки;
- полные описания этапов со ссылками на официальные источники;
- история изменений календаря и уведомления об обновлённых данных;
- светлая, тёмная и автоматическая темы;
- сохранение размера, положения и развёрнутого состояния окна;
- исправленная ссылка и QR-код раздела поддержки разработки;
- повторный показ краткого обзора после первоначальной настройки;
- безопасное фоновое обновление данных и приложения;
- установленная и Portable-сборки для Windows x64.

## Установка

- `MarkingCalendar-Setup.exe` — рекомендуемый вариант;
- `MarkingCalendar-Portable.zip` — версия без установки;
- `SHA256SUMS.txt` — контрольные суммы файлов выпуска.

Требуются Windows 10/11 x64, .NET 10 Desktop Runtime x64 и Microsoft Edge WebView2 Runtime. Установщик проверяет наличие .NET и при необходимости предлагает загрузить официальный runtime.

## Важно

Приложение не является официальным продуктом оператора системы «Честный знак». Данные предназначены для справочного использования; юридически значимые решения следует сверять с нормативными актами и официальными публикациями.

Сборки пока не подписаны сертификатом издателя, поэтому Microsoft Defender SmartScreen может показать предупреждение при первом запуске. Сверьте SHA-256 файла с `SHA256SUMS.txt` этого выпуска.
