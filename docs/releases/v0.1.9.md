# Календарь маркировки 0.1.9

Загруженное обновление теперь видно в основном окне. Приложение показывает ненавязчивую плашку с номером новой версии и предлагает перезапуститься сразу или вернуться к установке при следующем запуске.

## Установка

- **MarkingCalendar-Setup.exe** — обычная установка для Windows.
- **MarkingCalendar-Portable.zip** — переносимая версия.
- **SHA256SUMS.txt** — контрольные суммы файлов.

Автоматическое обновление использует служебные файлы `releases.win.json` и `MarkingCalendar-0.1.9-full.nupkg`.
