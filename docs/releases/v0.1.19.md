# Календарь маркировки 0.1.19

## Что нового

- В открытой карточке события под самими событиями появился список товаров группы: понятные наименования, условия и исключения. Кнопка «Страница группы на ЧЗ» доступна и у событий без собственной ссылки.
- Встроены 49 действующих перечней ЧЗ — 349 товарных строк. Они доступны без сети и обновляются отдельно от календаря и приложения. Общий поиск по названию, ТН ВЭД и ОКПД 2 доступен через `Справка` → `Товарные перечни`.
- Добавлены 176 проверенных расшифровок кодов ЕЭК. Исходные коды и оговорки ЧЗ сохраняются; просмотр перечней не меняет профиль и фильтры календаря.
- Ежедневный сборщик проверяет все 50 групп. При ошибке он сохраняет прежние данные группы, продолжает обновлять остальные и отправляет сопровождающему Telegram-уведомление с причиной и ссылкой на диагностику.

## Известное ограничение

Старая страница группы «Средства гигиены» на сайте ЧЗ возвращает HTTP 404. Её перечень пока недоступен; группа остаётся под контролем сборщика. Расшифровки кодов являются справочной информацией, включая коды из исключений, и сами по себе не определяют обязательность маркировки конкретного товара.

## Обновление

Установленное приложение получит обновление обычным способом. Также можно установить `MarkingCalendar-Setup.exe` поверх предыдущей версии. Для Portable скачайте новый архив. Профиль и пользовательские настройки сохраняются.

## Файлы

- `MarkingCalendar-Setup.exe` — установщик Windows x64.
- `MarkingCalendar-Portable.zip` — архив без автообновления.
- `SHA256SUMS.txt` — контрольные суммы.
- `releases.win.json` и `MarkingCalendar-0.1.19-full.nupkg` — файлы автообновления.
