# Календарь маркировки 0.1.13

## Что исправлено

- Исправлена ошибка, из-за которой найденные изменения могли сохраниться в истории, но не появиться в окне приложения. Повторная проверка без новых данных не закрывает непрочитанные изменения.
- Пока приложение открыто, календарные данные проверяются каждые 3 часа. Перезапускать программу для этого не нужно. Одновременные проверки не дублируются, при закрытии загрузка отменяется.
- Неполный ответ источника больше не может заменить календарь, если число событий сократилось ниже половины прежнего набора. В этом случае остаётся последняя корректная версия.
- При ошибке проверки приложение завершает статус загрузки и записывает причину в журнал. Заметки следующих выпусков публикуются из подготовленного Markdown без искажения имён файлов.

Автозапуск и постоянная иконка в трее не добавлены. Проверка обновлений самой программы в этом выпуске не менялась.

## Установка

- `MarkingCalendar-Setup.exe` — рекомендуемая установка.
- `MarkingCalendar-Portable.zip` — переносимый архив.
- `SHA256SUMS.txt` — контрольные суммы.

Служебные файлы `releases.win.json` и `MarkingCalendar-0.1.13-full.nupkg` используются автоматическим обновлением приложения.
