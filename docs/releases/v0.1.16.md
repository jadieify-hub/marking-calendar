# Календарь маркировки 0.1.16

## Что нового

Над списком товарных групп появились кнопки **«Выбрать все»** и **«Снять все»**. Они меняют выбор сразу для всех групп, включая скрытые поиском. Выбор сохраняется в профиле; кнопка недоступна, когда её действие уже выполнено.

## Обновление

Установленное приложение получит обновление обычным способом. Можно также установить `MarkingCalendar-Setup.exe` поверх предыдущей версии. Для Portable скачайте новый архив.

## Файлы

- `MarkingCalendar-Setup.exe` — установщик Windows x64.
- `MarkingCalendar-Portable.zip` — архив без автообновления.
- `SHA256SUMS.txt` — контрольные суммы.
- `releases.win.json` и `MarkingCalendar-0.1.16-full.nupkg` — файлы автообновления.
