# Календарь маркировки 0.1.6

Исправлен повторный запуск приложения. Ошибка `RPC_E_CHANGED_MODE` могла возникать при любом следующем запуске, если в каталоге данных уже была сохранена карта товарных групп, а не только после автоматического обновления. Инициализация интерфейса теперь всегда выполняется в UI-потоке.

Версия 0.1.5 снята с публикации из-за этой ошибки.
