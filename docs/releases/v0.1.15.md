# Календарь маркировки 0.1.15

## Что исправлено

- Ошибка записи истории больше не оставляет новый календарь без пакета изменений. Повторная проверка после устранения ошибки сохраняет обновление один раз.
- Повреждённый JSON настроек сохраняется отдельно; приложение запускается с начальными настройками и сохранённым календарём.
- Выбор товарных групп согласован между боковым списком, профилем и историей. Явные ручные настройки сохраняются при изменении отраслей; быстрые действия не откатывают профиль в интерфейсе или после перезапуска.
- Фоновые сообщения не сбрасывают читаемые диалоги; можно отключить все категории календаря.
- Экспорт сохраняет UID распознанных событий при переносах и правках. Поведение повторного импорта зависит от календарной программы.
- Публикация релиза требует успешных проверок коммита тега.
- Ссылка и QR-код поддержки обновлены; уточнены требования сборки и описание возможностей.

## Установка и ограничения

Установленное приложение предложит обновление обычным способом. Можно также установить `MarkingCalendar-Setup.exe` поверх предыдущей версии; календарь, история и профиль сохраняются. Для Portable скачайте новый архив.

Стабильность UID действует для распознанных соответствий событий между экспортами. Ранее импортированные файлы автоматически не меняются; обновление существующих записей при повторном импорте в Outlook отдельно не проверено.

## Файлы

- `MarkingCalendar-Setup.exe` — установщик Windows x64.
- `MarkingCalendar-Portable.zip` — архив без автообновления.
- `SHA256SUMS.txt` — контрольные суммы.
- `releases.win.json` и `MarkingCalendar-0.1.15-full.nupkg` — файлы автообновления.
