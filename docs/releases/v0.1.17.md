# Календарь маркировки 0.1.17

## Исправления

Кнопки **«Выбрать все»** и **«Снять все»** больше не перезаписывают группы, сохранённые при настройке профиля. Они переключают календарь в режим **«Все»** и меняют только временный выбор, включая группы, скрытые поиском.

Ручные изменения галочек в режиме «Все» также не затрагивают профиль. Возврат в **«Только мои»** показывает сохранённые группы. Временный выбор сохраняется при переключении режимов и обновлении данных; сброс фильтров снова показывает все группы.

Если профиль уже был перезаписан кнопками в версии 0.1.16, исправление не восстанавливает прежний выбор автоматически. Его можно заново задать через «Справка» → «Настроить профиль».

## Обновление

Установленное приложение получит обновление обычным способом. Можно также установить `MarkingCalendar-Setup.exe` поверх предыдущей версии. Для Portable скачайте новый архив.

## Файлы

- `MarkingCalendar-Setup.exe` — установщик Windows x64.
- `MarkingCalendar-Portable.zip` — архив без автообновления.
- `SHA256SUMS.txt` — контрольные суммы.
- `releases.win.json` и `MarkingCalendar-0.1.17-full.nupkg` — файлы автообновления.
