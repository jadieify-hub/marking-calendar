# Календарь маркировки 0.1.22

Исправлен пустой экран после обновления до 0.1.21. Если история содержала добавление, удаление или переименование товарной группы, проверка сообщений интерфейса отвергала всё состояние календаря. Теперь новые типы изменений проходят проверку и календарь отображается.

Ошибка не удаляла сохранённые данные и настройки. Переустановка со сбросом данных не требуется. Исправления истории и фильтров из 0.1.21 сохранены.

Добавлена регрессионная проверка передачи сообщения приложения через мост интерфейса до заполнения списка групп, категорий, статуса и истории.

## Обновление

Если в 0.1.21 отображается пустой экран и кнопки обновления недоступны, закройте приложение и установите `MarkingCalendar-Setup.exe` поверх текущей версии. Для Portable замените файлы программы новым архивом. Профиль и настройки сохраняются.

## Файлы

- `MarkingCalendar-Setup.exe` — установщик Windows x64.
- `MarkingCalendar-Portable.zip` — архив без автообновления.
- `SHA256SUMS.txt` — контрольные суммы.
- `releases.win.json` и `MarkingCalendar-0.1.22-full.nupkg` — файлы автообновления.
