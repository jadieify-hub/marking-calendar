# Календарь маркировки 0.1.21

## Что исправлено

- История показывает, какая товарная группа переименована: старое название → новое. Вместо противоречивого «0 изменений» переименование учитывается в общем количестве изменений.
- Добавление, удаление и переименование групп видны в истории, сравнении с сохранённой версией, уведомлении и скопированной сводке. Исправлены также публичный журнал и Atom-лента.
- При переименовании группы фильтры показывают новое название и сохраняют выбор. Это работает и для сохранённых «Моих групп», и для временного выбора в режиме «Все».
- Исправлено сохранение ручного исключения группы при переименовании: снятая галочка не теряется из настроек.

Сохранённые записи истории не требуют повторной загрузки: новая версия показывает подробности уже полученных переименований.

## Обновление

Установленное приложение получит обновление обычным способом. Можно установить `MarkingCalendar-Setup.exe` поверх предыдущей версии. Для Portable скачайте новый архив. Профиль и настройки сохраняются.

## Файлы

- `MarkingCalendar-Setup.exe` — установщик Windows x64.
- `MarkingCalendar-Portable.zip` — архив без автообновления.
- `SHA256SUMS.txt` — контрольные суммы.
- `releases.win.json` и `MarkingCalendar-0.1.21-full.nupkg` — файлы автообновления.
