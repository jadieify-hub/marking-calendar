# Календарь маркировки 0.1.4

Исправление автоматической проверки обновлений на Windows.

## Что изменилось

- приложение переведено на стабильную среду выполнения .NET 8;
- устранён обрыв TLS-соединения с GitHub, из-за которого не работали автоматические обновления;
- сообщение при временной сетевой ошибке стало понятнее и спокойнее;
- карточки ближайших событий стали крупнее и легче читаются;
- при отсутствии новой версии по-прежнему отображается статус «Установлена последняя версия».

## Установка

- `MarkingCalendar-Setup.exe` — рекомендуемый вариант;
- `MarkingCalendar-Portable.zip` — версия без установки;
- `SHA256SUMS.txt` — контрольные суммы файлов выпуска.

Для перехода с версии 0.1.3 на 0.1.4 установщик нужно запустить вручную. После этого последующие обновления будут проверяться и загружаться автоматически.

Требуются Windows 10/11 x64, .NET 8 Desktop Runtime x64 и Microsoft Edge WebView2 Runtime. Установщик проверяет наличие .NET и при необходимости предлагает загрузить официальный runtime.

## Важно

Приложение не является официальным продуктом оператора системы «Честный знак». Данные предназначены для справочного использования; юридически значимые решения следует сверять с нормативными актами и официальными публикациями.

Сборки пока не подписаны сертификатом издателя, поэтому Microsoft Defender SmartScreen может показать предупреждение при первом запуске. Сверьте SHA-256 файла с `SHA256SUMS.txt` этого выпуска.
