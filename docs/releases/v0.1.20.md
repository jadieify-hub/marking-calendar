# Календарь маркировки 0.1.20

## Исправления товарных перечней

- Общие описания кодов ТН ВЭД больше не выдаются за товары конкретной группы и не используются для поиска по названию. Вода, сахар или мясо из классификатора больше не приводят к спортивному питанию.
- Перепроверены все 49 доступных перечней. Исправлен охват восьми групп: спортивного питания, напитков, меховых изделий, икры, кресел-колясок, полимерных труб, растворимых напитков и электронных сигарет. В икре показываются осетровые и лососевые; исторические строки про телефоны и реле не выдаются за электронные сигареты.
- Уточнения возраста, назначения, исключения и дополнительные классификаторы сохранены. Товары остаются под событиями в открытой карточке, рядом доступна страница группы ЧЗ. Просмотр не меняет профиль и фильтры.
- Названия и пояснения получает сборщик из страниц ЧЗ, включая официальный FAQ. Общие расшифровки ЕЭК доступны отдельно в подробностях кодов.
- Сборщик сообщает о новых ошибках и восстановлении. Неизменившаяся ошибка больше не вызывает ежедневных повторных сообщений; неудачная доставка не считается подтверждённой.

## Ограничения источников

ЧЗ публикует для спортивного питания определение категории и условия СГР, но не подробный список привычных видов товаров. Для безалкогольных напитков загруженный перечень также не содержит отдельных наименований. Приложение прямо сообщает об этих ограничениях, не придумывая список по кодам. Старая страница «Средства гигиены» по-прежнему возвращает 404; её перечень недоступен и остаётся под контролем сборщика.

## Обновление

Новая версия использует формат товарного каталога 2. Старый кеш не перекрывает исправленные встроенные данные. Предыдущие версии программы сохраняют свой прежний каталог до обновления приложения.

Установленное приложение получит обновление обычным способом. Можно установить `MarkingCalendar-Setup.exe` поверх предыдущей версии. Для Portable скачайте новый архив. Профиль и настройки сохраняются.

## Файлы

- `MarkingCalendar-Setup.exe` — установщик Windows x64.
- `MarkingCalendar-Portable.zip` — архив без автообновления.
- `SHA256SUMS.txt` — контрольные суммы.
- `releases.win.json` и `MarkingCalendar-0.1.20-full.nupkg` — файлы автообновления.
