# Календарь маркировки 0.1.28

История изменений стала проще: дата проверки и конкретные изменения под ней.

- Убраны сравнение со снимками и плитки со счётчиками на странице истории.
- Внутри каждой даты изменения собраны по типу: переносы сроков, добавленные, изменённые и удалённые события, изменения товарных групп.
- Переименования групп показаны компактным списком «старое название → новое», без повторяющихся заголовков.
- Фильтр «Мои группы / Все» сохранён. Даты и разделы без подходящих изменений скрываются.
- Сохранены подробности «было / стало», копирование полной сводки проверки и переход к нужной записи из уведомления.

## Обновление

Установленная версия загрузит обновление автоматически. Для ручного обновления запустите `MarkingCalendar-Setup.exe` поверх текущей версии. Для Portable замените файлы программы новым архивом. Профиль и настройки сохраняются.

## Файлы

- `MarkingCalendar-Setup.exe` — установщик Windows x64.
- `MarkingCalendar-Portable.zip` — архив без автообновления.
- `SHA256SUMS.txt` — контрольные суммы.
- `releases.win.json` и `MarkingCalendar-0.1.28-full.nupkg` — файлы автообновления.
