# Календарь маркировки 0.1.18

## Исправления

- В индикаторе актуальности разделены **«Данные от…»** — дата снимка календаря и **«Проверено…»** — время последней успешной проверки в текущем запуске приложения. Время проверки обновляется и тогда, когда новых событий или изменений нет. При ошибке сохраняется время предыдущей успешной проверки; до первой проверки показано «Ещё не проверено».
- Дата снимка отображается в местном времени. Переключение фильтров больше не заменяет даты в индикаторе счётчиком событий; счётчик остаётся над лентой.
- Названия **«Объёмно-сортовой учёт»** и **«Разрешительный режим»** полностью помещаются в колонке этапов в одну строку.

## Обновление

Установленное приложение получит обновление обычным способом. Можно также установить `MarkingCalendar-Setup.exe` поверх предыдущей версии. Для Portable скачайте новый архив.

## Файлы

- `MarkingCalendar-Setup.exe` — установщик Windows x64.
- `MarkingCalendar-Portable.zip` — архив без автообновления.
- `SHA256SUMS.txt` — контрольные суммы.
- `releases.win.json` и `MarkingCalendar-0.1.18-full.nupkg` — файлы автообновления.
