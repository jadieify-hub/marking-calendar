# Календарь маркировки 0.1.7

Товарные группы стало проще различать в длинной ленте: рядом с названиями в фильтре и карточках появились спокойные контурные иконки. Названия по-прежнему остаются основным ориентиром, поэтому смысл не зависит от изображения.

На высоких экранах список товарных групп теперь занимает больше доступного места и показывает больше строк без прокрутки. Категории и остальные фильтры при этом остаются на экране.
