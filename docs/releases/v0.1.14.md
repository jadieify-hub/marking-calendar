# Календарь маркировки 0.1.14

## Что исправлено

- Обновления приложения теперь проверяются и загружаются через `raw.githubusercontent.com`. Это устраняет зависимость основного канала от соединения с `github.com`, которое на некоторых компьютерах в РФ обрывалось при проверке обновлений.
- Если основной канал недоступен, приложение один раз проверяет GitHub Releases. Отсутствие новой версии не считается ошибкой.
- В журнал записываются успешные проверки: «обновлений нет» или «загружена версия …». При сетевой ошибке сохраняется полная цепочка причин, включая ошибки TLS.

Новый канал содержит два последних полных пакета. Старые выпуски остаются доступны на странице GitHub Releases. Порядок установки обновлений и проверка календарных данных не менялись.

Если предыдущая версия не может проверить обновления, скачайте `MarkingCalendar-Setup.exe` этого выпуска и установите поверх существующей. Профиль и история сохранятся; следующие проверки будут использовать новый канал.

## Файлы

- `MarkingCalendar-Setup.exe` — рекомендуемая установка.
- `MarkingCalendar-Portable.zip` — переносимый архив без автообновления.
- `SHA256SUMS.txt` — контрольные суммы.
- `releases.win.json` и `MarkingCalendar-0.1.14-full.nupkg` — служебные файлы автообновления.
