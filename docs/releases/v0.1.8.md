# Календарь маркировки 0.1.8

В блоке «Ближайшее» на первый план вынесены дата и товарные группы. Названия групп теперь показаны отдельными строками с иконками, а срок и количество событий стали вторичной информацией.

Основной текст интерфейса увеличен на один пункт. При первом запуске окно занимает 75% рабочей ширины экрана, чтобы длинные строки календаря чаще помещались без переноса. Размер, который пользователь установил самостоятельно, по-прежнему сохраняется.

## Установка

- **MarkingCalendar-Setup.exe** — обычная установка для Windows.
- **MarkingCalendar-Portable.zip** — переносимая версия.
- **SHA256SUMS.txt** — контрольные суммы файлов.

Автоматическое обновление использует служебные файлы `releases.win.json` и `MarkingCalendar-0.1.8-full.nupkg`.
