# Календарь маркировки 0.1.24

На вкладке «Изменения» плитки-счётчики стали фильтром. Нажмите «Перенесено», «Добавлено», «Изменено», «Удалено» или плитку изменений групп, чтобы оставить в истории и сравнении снимков только этот вид изменений. Повторное нажатие возвращает полный список.

- Плитка с нулём неактивна, выбранная плитка подсвечена.
- Если в пакете истории нет изменений выбранного вида, вместо списка показывается короткое пояснение.
- Фильтр не меняет сохранённый профиль и не влияет на окно с уведомлением о новых изменениях.

Названия 26 товарных групп в карте отраслей приведены к новым официальным названиям «Честного знака», например «Обувь» теперь «Обувные товары», а «Табак» — «Табачная продукция». Исчезли предупреждения о расхождении названий в журнале. Группы «Спортивное питание» и «БАД» источник объединил под одним названием, в календаре это одна группа.

## Обновление

Установленная версия загрузит обновление автоматически. Для ручного обновления запустите `MarkingCalendar-Setup.exe` поверх текущей версии. Для Portable замените файлы программы новым архивом. Профиль и настройки сохраняются.

## Файлы

- `MarkingCalendar-Setup.exe` — установщик Windows x64.
- `MarkingCalendar-Portable.zip` — архив без автообновления.
- `SHA256SUMS.txt` — контрольные суммы.
- `releases.win.json` и `MarkingCalendar-0.1.24-full.nupkg` — файлы автообновления.
