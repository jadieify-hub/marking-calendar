# Календарь маркировки 0.1.29

Исправлена прокрутка окна на Full HD и при ограниченной доступной высоте.

- Переход к ближайшему событию больше не сдвигает шапку за верхнюю границу окна.
- Исправление также применяется к переходам по годам и к записям истории изменений.
- Боковая панель фильтров получила собственную прокрутку. Нижние переключатели, экспорт, печать и сохранение PDF доступны, даже когда панель не помещается целиком.

## Обновление

Установленная версия загрузит обновление автоматически. Для ручного обновления запустите `MarkingCalendar-Setup.exe` поверх текущей версии. Для Portable замените файлы программы новым архивом. Профиль и настройки сохраняются.

## Файлы

- `MarkingCalendar-Setup.exe` — установщик Windows x64.
- `MarkingCalendar-Portable.zip` — архив без автообновления.
- `SHA256SUMS.txt` — контрольные суммы.
- `releases.win.json` и `MarkingCalendar-0.1.29-full.nupkg` — файлы автообновления.
