# Календарь маркировки 0.1.27

Небольшое исправляющее обновление.

- После обновления приложение сразу использует более свежую карту товарных групп. Раньше оно могло ещё сутки показывать старые названия групп, пока не синхронизирует общую историю.
- Журнал приложения больше не повторяет одно и то же предупреждение о расхождении названий групп при каждой проверке: каждое расхождение записывается один раз за запуск.

## Обновление

Установленная версия загрузит обновление автоматически. Для ручного обновления запустите `MarkingCalendar-Setup.exe` поверх текущей версии. Для Portable замените файлы программы новым архивом. Профиль и настройки сохраняются.

## Файлы

- `MarkingCalendar-Setup.exe` — установщик Windows x64.
- `MarkingCalendar-Portable.zip` — архив без автообновления.
- `SHA256SUMS.txt` — контрольные суммы.
- `releases.win.json` и `MarkingCalendar-0.1.27-full.nupkg` — файлы автообновления.
