# Семантический аудит товарных перечней — 2026-09-19

Проверены HTML перечней всех 49 доступных групп из инвентаризации от 18 сентября; дополнительно 19 сентября прочитаны официальные FAQ sportpit, fur, beverages и текущие landing/goods sportpit. Это результаты исследования до исправлений; реализация описана в product-lists.md.

## Главный результат

Точная расшифровка ТН ВЭД не является названием товара в области маркировки. Для sportpit код описывает значительно более широкий класс (вода, сахар, жиры, химические вещества), а охват сужают предназначение для спортсменов и СГР. Такие расшифровки допустимы в справке по коду, но не в перечне товаров группы и не как основание текстового поиска «какая группа маркирует воду».

## Официальные FAQ и воспроизводимое извлечение

Общий устойчивый выбор: в `section.section-content` найти `.qa-block`, у которого нормализованный текст `.qa-block__question` точно совпадает с вопросом. Затем `.qa-block__answer`; не использовать порядковый номер вопроса или динамический `id`.

### sportpit

Источник: https://честныйзнак.рф/business/projects/sportpit/faq/
Вопрос: «Какие товары подлежат обязательной маркировке?».
Fixture: `../tests/fixtures/product-scopes/sportpit.html` — один исходный QA-блок, без навигации.

В ответе есть отдельный прямой `p`, начинающийся «Для спортивного питания». Он содержит точную категорию: «специализированная пищевая продукция для питания спортсменов». Его можно выбрать по префиксу, затем извлечь содержимое русских кавычек. Проверять единственность абзаца и наличие цитаты; не брать предыдущий абзац «Для БАД».

Другой прямой `p`, начинающийся «В целях определения продукции», устанавливает совместное использование кодов ТН ВЭД, ОКПД2 и свидетельства СГР, выданного на пищевую продукцию для питания спортсменов. Это готовый проверяемый scope.description. Абзац «Согласно подпункт…» дополнительно объясняет код продукции 007 в СГР и необходимость смотреть наименование/область применения.

В HTML landing/goods/FAQ не найдены текстовые примеры протеина, гейнера, батончиков или изотоников. После «Для примера» стоят два изображения свидетельств: Рисунок1.jpg относится к БАД, Рисунок2.jpg содержит коммерческое название креатина. Это иллюстрация различий СГР, НЕ перечень видов спортпита. Не добавлять название с картинки в productNames автоматически и не делать OCR частью штатного сбора.

### fur

Источник: https://честныйзнак.рф/business/projects/fur/faq/
Вопрос: «Какие товары из меха следует маркировать?».
Fixture: `../tests/fixtures/product-scopes/fur.html`.

Первый непустой прямой `p` ответа начинается «Следует маркировать предметы одежды из натурального меха» и перечисляет норку, нутрию, песца, лисицу, кролика, зайца, енота, овчину и другие виды меха. Он также охватывает одежду с натуральной меховой подкладкой и мехом снаружи, кроме только отделки. Два следующих непустых `p` объясняют отделку и исключения. Это реальное определение охвата, которого нет в code-only таблице. Можно собирать три абзаца в scope.description; узкий список названий из таблицы всё равно не появляется. Не придумывать отдельные «шубы/жилеты/шапки»: шапки здесь прямо исключены.

### beverages

Источник: https://честныйзнак.рф/business/projects/beverages/faq/
Fixture: `../tests/fixtures/product-scopes/beverages.html`.

В FAQ нет текстового списка соков, лимонадов, морсов, кваса и т. п. Проверен весь блок section-content. Найден вопрос о напитках с коротким сроком годности; ответ подтверждает напитки в потребительской упаковке при указанных кодах ТН ВЭД/ОКПД2, без исключений по сроку годности/объёму/месту производства. Это дополнительное условие, НЕ источник конкретных товарных названий. В goods есть только парные коды и стадии по упаковке. ProductNames оставить пустым с ясным объяснением границы источника; не превращать код 2008 в утверждение «консервированные фрукты маркируются как напитки».

## Остальные группы: использование имён и обязательные оговорки

- grocery: ЧЗ сам даёт бытовые группы снеков, соусов, специй и т. п. Использовать эти sourceName с исключениями по массе; не расширять расшифровками кодов.
- nonalcoholic_beer: отдельное корректное имя «Безалкогольное пиво», с условием одновременного соответствия кодам.
- babyfood: два конкретных имени в одноколоночных заголовках корректны. Не терять возраст «до трёх лет» / «до одного года» и потребительскую упаковку. Общие названия кодов молока/сыра/консервов не заменяют эти имена.
- dietarysup: карточки дают БАД, а не список всех растений/жиров/химикатов из кодов. Сохранить условие действующего СГР на БАД; стадии не являются разными видами товаров.
- groceries, sweets, meat: многие имена формально совпадают с классификатором, но ЧЗ уточняет их в самой строке/названии группы и исключениях. Сохранять полный текст после «в части», «например», «за исключением»; не сокращать до широкой первой части. meat хранит две колонки названий, их связь с ОКПД2 нельзя терять.
- medical_devices, medproducts, technical_rehabilitation: названия читаемы, но остаются обязательными дополнительные медицинские/реабилитационные классификаторы. «Салфетки» не означает любые бытовые салфетки.
- fertilizers/oil/canned_food/cement: потребительская упаковка и назначение/определение группы существенны. Удобрения: отдельно исключено исключительно сельскохозяйственное производство. Масла: исключены животное/микробиологическое происхождение, БАД и малая масса. Консервы: определение герметичной упаковки/обработки.
- children/light_industry/antiseptic/cosmetics/low_alcohol/semi_frozen: читать имена вместе с исключениями возраста, назначения, медизделий, других маркируемых групп и т. п. У cosmetics есть подтверждённые бытовые examples на самой goods-странице; их разрешено использовать с исходными категориями.
- water: только питьевая вода перечисленных карточек, исключения включают лёд/снег; словарное имя ТН2201 содержит их, поэтому не переносить его в productNames.
- Остальные 20 групп имеют самостоятельные sourceName, пригодные для отображения с уже сохранёнными условиями: autoparts, bicycles, veterinary_products, perfumes, cables, pet_food, medicines, dairy, autofluids, footwear, optical_fiber, heating_devices, books, beer, pyrotechnics, radioelectronics, tobacco, homeware, photo_cameras_and_flashbulbs, tyres. Это не отменяет родных уточнений в названиях (например, новые шины, мощность/напряжение, лекарственное назначение).

## Автоматическая проверка смысла

Раздельно хранить source rows, словарь кодов и именованный scope. Для FAQ контролировать вопрос, непустой ответ и смысловые якоря (sportpit: спортсменов + СГР; fur: натурального меха + подкладку + отделкой). Для caviar не удалять общий ограничитель. productNames не должны пополняться через meanings; текстовый поиск по бытовому товару не должен находить спортпит лишь по широкому коду воды/сахара.
