# Идеи развития

Список того, что обсуждалось, но ещё не сделано. Обновляется вручную. Не план и не обязательства — снимок решений, чтобы они не терялись между сессиями.

## В работе

- **Товарные перечни всех групп.** Перечни внутри карточек событий, проверка 50 источников и Telegram-оповещения об ошибках сборщика. Подробности: [план расширения](superpowers/plans/2026-09-18-all-product-groups.md).

## Готово

- **Экспорт событий в `.ics`.** В боковой панели можно выгрузить события, видимые после текущих фильтров, в файл рабочего календаря.
- **Уведомление об изменениях.** Пока приложение работает, оно показывает системное уведомление о новом пакете изменений, если окно не активно.

## Обсуждено, отложено

- **Автозапуск.** Ключ `Run` в реестре, запуск свёрнутым в панель задач. Резидентом в трее приложение сознательно не делаем: это требует меню «Выйти», переопределения закрытия окна и объяснений пользователю, а на Windows 11 иконка прячется в переполнение и её не находят. Главная техническая тонкость — в реестр надо писать путь к стаб-файлу Velopack в корне установки, а не к версионной папке `current`, иначе автозапуск сломается после первого обновления. Решение отложено 2026-09-04.
- **Ретроспектива по группе.** «Детские игрушки переносили 4 раза, суммарно на 18 месяцев». Данные уже есть в `history/changes.json`, нужен подсчёт и подача. Прямое усиление главной особенности проекта — отслеживания изменений.
- **Telegram-канал.** Runner уже умеет отправлять анонсы, секреты в workflow заложены, канал не создан. Самый дешёвый способ привлечь пользователей.
- **Веб-версия календаря на GitHub Pages из ветки `data`.** Ветка публичная, лента уже собрана на TypeScript. Даёт ссылку, которую можно переслать, и вход для тех, кто не ставит приложения. Риск — расползание кода на две сборки.

## Отклонено

- **Отдельная вкладка-справочник «Товары».** Поиск товара в отрыве от календаря — работа сервиса проверки кодов, который у «Честного знака» уже есть отдельной страницей, и ссылка на него лежит прямо на странице группы.
- **Перечень товаров внутри карточки календаря.** Раздел «Исключения» на официальных страницах занимает полтора экрана; короткая строка вида «Крупы, мука, макароны…» без него вводит в заблуждение.
