# Простая история изменений

**Цель:** согласованная лента «дата → изменения», новые записи сверху. Убрать сравнение снимков и фильтры по виду изменения. Оставить «Мои группы / Все», копирование сводки, подробности текста и переходы из уведомлений. Даты без подходящих записей скрывать.

**Решение:** локальная правка существующего TypeScript-рендера и CSS без новых зависимостей. Использовать готовые записи истории и их порядок с сервера. Сохранить дату и время каждой проверки для различения нескольких обновлений за день. Архивы, сборщик и сохранённые данные не менять. Копирование сводки проверки остаётся существующим; кнопка явно сообщает, что копирует все изменения проверки.
