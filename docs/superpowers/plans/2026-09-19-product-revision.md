# Ревизия товарных перечней

Исправить смысл данных, а не только свернуть длинные описания.

1. Проверить все 49 доступных источников: наименования, ограничения и исключения. Отдельно проверить источники без названий товаров и строки классификатора с более широким охватом, чем группа.
2. Отделить подтверждённое содержание группы от исходных классификационных строк. Получать его из источника сборщиком; при отсутствии названий явно сообщать об этом. Сохранить исходные коды и условия для проверки.
3. В карточке оставить события → ссылку группы → товары. Поиск по названию не должен находить группу по общему описанию кода. Полные наименования ЧЗ ищутся вместе с их оговорками; результат не подтверждает принадлежность исключённого товара к группе. Проверить тот же сценарий в справочнике.
4. Уведомлять об изменении состояния сборщика: новый сбой и восстановление. Сохранять подтверждение только после доставки; неизменный сбой не повторять ежедневно.
5. Проверить регрессии, сборку и интерфейс. Составить итог ревизии с реальными ограничениями источников. Без публикации релиза.
