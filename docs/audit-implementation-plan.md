## 1. Срочный отдельный выпуск 0.1.13

Цель: найденные изменения доходят до интерфейса, частичный ответ не подменяет календарь, долго открытое приложение продолжает проверять данные.

Решение: сохранить существующие Core/Infrastructure/WPF и формат состояния. В `AppBootstrapper` использовать диспетчер окна и один `DispatcherTimer` раз в 3 часа. Все способы запуска проверки проходят через одну защиту от параллельного выполнения и один обработчик ошибок. При закрытии остановить таймер, отменить проверку и освободить её ресурсы после завершения.

Ограничения: без новых зависимостей, автозапуска, постоянной иконки в трее, изменения VPS, ветки `data`, схем снимков и карты групп. Периодическая проверка касается календарных данных; механизм обновления самого приложения не расширяется.

## 2. Оставшаяся надёжность

Отдельный набор после 0.1.13:

1. Сохранять явные ручные включения и исключения групп, даже если выбор совпадает с отраслевым. Проверка: ручной БАД переживает выбор и снятие отраслей, сохранение и перезапуск.
2. Согласовать боковую панель, профиль и историю: новый локальный выбор сразу виден в профиле, авторитетные изменения/переименования от хоста применяются. Не передавать полный снимок на каждый клик.
3. Восстанавливать запуск при повреждённом JSON настроек, сохранив повреждённый файл для разбора. Ошибки прав доступа не маскировать под повреждение.

1. Не пересоздавать читаемый диалог при обновлении статуса загрузки; сохранять прокрутку, фокус и раскрытые разделы профиля.

3. Проверить доступность нижних действий при 800–900 CSS px высоты и увеличенном масштабе Windows. Выделять группам остаток высоты, не возвращать второй скролл всей боковой панели.
4. Исправить контраст текста категорий светлой темы и текста на основных кнопках тёмной темы. Проверить минимум 4,5:1 для обычного текста и обе темы в настоящем окне.
